# FAQ | 常见问题

**Q1：这是什么？**
方法论 + 零依赖回归门禁 + 宣称边界的技能包。把 RSIFlow 四段思路落成可执行 SOP，用冻结任务集做护栏。

**Q2：是完整 RSI 吗？**
不是。名中 `rsi` 指 bounded 项目侧原型、`guarded` 指受护栏且方向裁决系统外。严格 RSI 完成态不可声称。

**Q3：全绿=能力变强？**
不是。`PASS` 只表示冻结基线回归未退化，不判方向、不判语义质量。

**Q4：能自动写回生产技能吗？**
本包刻意不自动批准、不自动写回——那是它要拦的洗绿动作。写回需人工授权 + 回滚路径。

**Q5：退出码 3 怎么办？**
任务集哈希与锁不符。要么恢复原任务集，要么人工确认后显式重算哈希锁（见 runnable-guide）。不自动重算去迁就被改的任务集。

**Q6：需要联网/API Key 吗？**
不需要。全部脚本零第三方依赖、离线可跑。

**Q7：新手从哪开始？**
先读 `getting-started.md`，按 0–5 步走；60 秒示例就在 SKILL.md 顶部。

**Q8：装了没生效？**
本包是方法论与工具包，不含 hook；「改了不生效」多指宿主加载问题，不适用本包。若指其他 skill，见 `unclekk-skill-dev-loop`。

**Q9：为什么在别的平台没自动触发？**
`triggers` 是给宿主的语义加载建议，不是本包能强制的开关，各平台规则不同。最稳的是直接说白话指令（「跑一遍四段闭环」「查退化没有」「这句话能不能说」）。详见 SKILL.md「不同平台怎么触发」。

**Q10：文档里的 N/N 和实际对不上怎么办？**
跑 `python3 scripts/check_doc_numbers.py`——它实跑每个脚本、核对全包 8 个活动文档的数字与真实输出，不一致 exit 1 并列出差异；还会校验 SKILL.md 文档地图与 `references/` 目录是否一致。改用例数后跑 `--print` 看新值再改文档。这是防止「说明数字漂移」的机器闸。更多易错点见 `references/pitfalls.md`。

**Q11：能发到 SkillHub 吗？**
可以，但对外字段（displayName/summary/description/version/license/tags）须先经所有者确认，且不得把项目侧原型写成严格完成态。
